MATERI 01 · DASAR HTML

Pengenalan tentang Website

Website adalah kumpulan halaman yang dapat diakses melalui internet menggunakan browser. Halaman tersebut dibangun dengan HTML untuk menyusun isi, CSS untuk mengatur tampilan, dan JavaScript untuk menambahkan interaksi.

Bagaimana website bekerja?

  • Pengguna membuka alamat web melalui browser, misalnya Chrome atau Firefox.
  • Browser meminta data ke server melalui internet.
  • Server mengirim file seperti HTML, CSS, JavaScript, gambar, atau video.
  • Browser membaca file tersebut lalu menampilkan halaman kepada pengguna.

Apa itu HTML?

  • HTML adalah singkatan dari HyperText Markup Language.
  • HTML bukan bahasa pemrograman; HTML adalah bahasa markup untuk memberi struktur pada halaman.
  • Struktur tersebut dibuat menggunakan elemen atau tag, contohnya judul, paragraf, tautan, dan gambar.

Tag HTML dasar

  • <h1> untuk judul utama.
  • <p> untuk sebuah paragraf.
  • <a> untuk membuat tautan.
  • <img> untuk menampilkan gambar.

Struktur dokumen

  • <!doctype html> memberi tahu browser bahwa dokumen memakai HTML5.
  • <head> berisi informasi halaman yang tidak tampil langsung.
  • <body> berisi seluruh konten yang terlihat oleh pengguna.

Contoh halaman HTML sederhana

<!doctype html>
<html lang="id">
  <head>
    <meta charset="UTF-8">
    <title>Website Pertamaku</title>
  </head>
  <body>
    <h1>Halo, dunia!</h1>
    <p>Saya sedang belajar membuat website.</p>
    <a href="https://example.com">Kunjungi tautan ini</a>
  </body>
</html>

Ingat: browser menerjemahkan struktur HTML menjadi tampilan halaman. Setelah memahami HTML, kamu dapat memperindahnya dengan CSS dan membuatnya lebih interaktif dengan JavaScript.
